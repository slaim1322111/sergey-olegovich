# Анализ безопасности операционной системы

Краткая лекция на 5 минут. Тема 3.

## Конфигурация ОС

Анализ безопасности ОС оценивает конфигурацию: службы, права, аутентификацию, журналирование и сетевые параметры. Поиск уязвимых версий пакетов дополняет эту работу, но проверяет другой набор условий. В Wazuh модуль Security Configuration Assessment сопоставляет настройки с правилами выбранной политики.

## Результат Wazuh SCA

Passed означает выполнение условий конкретного правила. Failed показывает, что правило не подтвердило требуемое состояние. Not applicable возникает, когда проверку нельзя оценить, например из-за отсутствующей команды или файла. Для интерпретации нужен текст правила и поле reason. Одна общая оценка не показывает причину каждого результата.

## Сверка с ALT Linux

На ALT Linux пути и компоненты могут отличаться от тех, которые ожидает общий профиль. Если правило проверяет /etc/ssh/sshd_config, а фактический файл находится в /etc/openssh/sshd_config, результат о правах требует проверки реального файла. Аналогично команда dpkg не подходит для проверки RPM-пакетов. Такие различия фиксируют до изменения системы.

## Практика за 10 минут

В практике выданы четыре синтетических результата и факты хоста. Отключённый auditd подтверждает одно замечание. Права 600 root:root у фактического SSH-файла показывают проблему применимости другого правила. Отсутствие команды оставляет проверку неоценённой. В протокол записывают вывод по каждому пункту, а рекомендации отделяют от выполненных изменений.
