# Итоговый экзамен

Можно пользоваться [нормативным реестром](norms.md) и пустой формой протокола. Ответы на кейс запишите короткими выводами с указанием факта или критерия.

## Часть А. Тест на 12 баллов

Выберите один вариант в каждом вопросе. Каждый верный ответ даёт 1 балл.

| № | Вопрос | А | Б | В |
|---|---|---|---|---|
| 1 | По какому документу в кейсе определяют УЗ? | ПП РФ № 1119 | Приказ ФСТЭК № 55 | RFC 9525 |
| 2 | Какой факт нужно уточнить, если известны данные, число и статус субъектов? | Номер TCP-порта | Имя таблицы БД | Тип актуальных угроз |
| 3 | Какой публичный ответ соответствует контракту Д2? | Только тело отправленной заявки | ID, статус и все контакты | ID и статус |
| 4 | Как проверить исправление логирования? | Сверить строку по ID запроса и убедиться, что в ней остались согласованные поля | Открыть только список файлов журнала | Проверить только код HTTP 201 |
| 5 | На какие данные опирается вывод о доступности SSH из пользовательской зоны? | Слушающий порт, маршрут, фильтрация и результат из зоны | Только слушающий адрес | Только права файла |
| 6 | Профиль SCA проверил отсутствующий файл. Какие данные нужны для вывода о правах? | Список установленных пакетов | Общий процент соответствия | Фактический путь, владелец и права рабочего файла |
| 7 | TCP-соединение успешно, PostgreSQL отклонил источник. Как описать наблюдение? | Порт заблокирован сетевым экраном | Порт достижим, допуск на уровне СУБД отклонён | Подтверждено чтение данных |
| 8 | Какие права нужны роли приложения по кейсу? | Чтение всех заявок | Вставка заявки и чтение ID и статуса для ответа | Полномочия DBA |
| 9 | Что подтвердит исправление фильтрации? | Только разрешённый поток | Только запись целевого правила | Отказ запрещённому соединению и сохранение нужных потоков |
| 10 | Цепочка доверия корректна, имя в SAN отличается от имени запроса. Каков результат проверки имени? | Успех по действующему сроку | Успех при доступном TCP | Отказ проверки имени |
| 11 | Карточка относится к версии 3.1, установлена 3.2. Что нужно запросить? | Снимок веб-формы | Реестровую запись и документы о применимости к установленной версии | Только имя продукта |
| 12 | Что оценивают при аттестации и сертификации СЗИ соответственно? | Объект информатизации и продукт в соответствующих процедурах | Только программную версию в обоих случаях | Только организацию в обоих случаях |

## Часть Б. Общий кейс на 8 баллов

Сервис клуба хранит иные ПДн 1 200 участников, не являющихся работниками оператора. По учебному паспорту актуальны угрозы третьего типа. Публичный ответ после создания заявки включает телефон. Узел слушает SSH на всех интерфейсах, соединение из пользовательской зоны блокируется, из сети управления проходит. Роль приложения читает всю таблицу заявок, хотя ей нужны ID и статус. Из пользовательской зоны TCP/5432 доступен, запись E106 показывает разрешение потока F6 правилом R90. Для внешнего HTTPS ожидается `zapis.trolli.example`, в SAN только `old.trolli.example`. В карточке СЗИ версия 3.1, установлена 3.2, подтверждающие документы о версии отсутствуют.

| № | Что представить | Баллы |
|---|---|---|
| Б1 | УЗ, основание и исходные условия | 2 |
| Б2 | Расхождение API и критерий повторной проверки | 1 |
| Б3 | Вывод о доступности SSH из обеих зон | 1 |
| Б4 | Целевой объём прав роли приложения | 1 |
| Б5 | Вывод по имени TLS и пара сетевых проверок для F6 и F3 | 2 |
| Б6 | Вывод о документальном охвате версии и перечень необходимых подтверждений | 1 |

Зачёт требует минимум 12 из 20 баллов по экзамену и минимум 4 из 8 за часть Б.
