# Защита сетевого веб-приложения

Клиент передаёт контакты при создании заявки. Ответ нужен ему для подтверждения, а журнал нужен оператору для диагностики.

У каждого канала свой допустимый набор полей.

## Два критерия для API

- Ответ HTTP 201 содержит идентификатор заявки и статус.
- Журнал содержит действие, время, идентификатор запроса и код результата.
- Просмотр заявок сотрудником требует отдельной проверки полномочий.

## Доказательства повторной проверки

Для обычной учебной заявки сверяют список полей ответа и соответствующую строку журнала.

Сохранность функции подтверждают создание заявки и выдача идентификатора.
