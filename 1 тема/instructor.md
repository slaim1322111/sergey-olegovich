# Материалы преподавателя

Преподаватель выдаёт [экзамен](exam.md) и [форму протокола](laba2.md#форма-протокола). Перед Т1 выдайте паспорт без абзаца Д1‑У и дождитесь, пока студенты запишут недостающий вход. Затем дайте Д1‑У и попросите найти конкретный подпункт применимого требования.

## Ориентиры для практических работ

| Тема | Ожидаемый вывод | Как выглядит повторная проверка |
|---|---|---|
| Т1 | В область входят шлюз, приложение, БД, управление и места хранения. Студент обосновывает поля записи на игротеку и запрашивает подтверждающий документ для указанного основания обработки. До Д1‑У тип угроз неизвестен. После вводной УЗ‑4 следует из подп. «б» п. 12 требований № 1119 | Уточнить паспорт при изменении данных, числа субъектов или определения угроз. Для F6 получить наблюдение из пользовательской зоны |
| Т2 | Д2.1 показывает лишние контакты в ответе, Д2.2 показывает лишнее тело в журнале | Заявка сохраняется, ответ 201 содержит только ID и статус. Строка журнала по тому же запросу содержит согласованные диагностические поля |
| Т3 | Д3.2 подтверждает допуск SSH из сети управления и блокировку из пользователей. Д3.4 удовлетворяет критерию файла. Д3.3 требует исправить путь в профиле | Сверить права рабочего файла и повторить оценку профилем с верным путём. Проверить доступ из обеих зон |
| Т4 | F6 проходит на уровне TCP и отклоняется СУБД. Целевая матрица закрывает TCP для пользователей, сохраняет TLS для приложения и DBA. `web_app` допускает вставку заявки и чтение только ID и статуса | Проверить подключение и создание из приложения, отсутствие TCP-доступа для пользователей и запрет чтения контактов ролью приложения |
| Т5 | F6 и F7 нарушают целевую матрицу. Для F1 SAN не соответствует ожидаемому имени | F1 проходит проверку TLS, F2 и F3 доступны по утверждённым каналам, F6 и F7 блокируются |
| Т6 | Запись E106 подтверждает разрешение F6 правилом R90 при выключенном запрете. Карточка 3.1 оставляет документальный охват 3.2 неопределённым | Получить событие deny для F6 и доказательство сохранения F3. Запросить сведения о сертификате, исполнении и охвате версии 3.2 |

Пример итогового заключения. «По выборке Д2–Д6 подтверждены лишние поля в ответе и журнале, избыточные права в БД, лишние потоки F6 и F7 и несовпадение имени TLS на F1. Для F6 причину подтверждает событие E106. Для версии 3.2 требуется уточнить документальный охват. После изменений нужно повторить проверку запрещённых и разрешённых потоков и сопоставить результаты с журналом».

## Баллы за общий кейс

| Пункт | Оценивание |
|---|---|
| Б1 | 1 балл за УЗ‑4 и подп. «б» п. 12 ПП № 1119. 1 балл за иные ПДн менее 100 000 участников, которые не являются сотрудниками, и третий тип угроз |
| Б2 | 1 балл за лишний телефон и повторный результат HTTP 201 с ID и статусом при сохранении создания заявки |
| Б3 | 1 балл за правильный вывод по обеим зонам с опорой на наблюдения. Адрес прослушивания сам по себе описывает локальную конфигурацию |
| Б4 | 1 балл за сохранение вставки и чтения только ID и статуса. Права на контакты избыточны |
| Б5 | 1 балл за несовпадение SAN и запрошенного имени. 1 балл за отказ TCP для F6 и сохранение TLS-соединения F3 |
| Б6 | 1 балл за вывод, что охват версии 3.2 пока не подтверждён, и запрос записи о сертификате и документов по версии или исполнению |

Эквивалентные по смыслу ответы засчитываются. Для зачёта проверяются оба порога. Баллы практик служат для обратной связи по протоколу.
