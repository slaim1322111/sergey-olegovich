# Сергей Олегович — материалы по сетевой АБАС

**[Весь переработанный курс одним Markdown-файлом](ABAS_full_course.md)** — сетевой контур ИСПДн, защита ПДн, все темы, учебные данные, экзамен и ответы.

Обзорное занятие по анализу безопасности сетевой автоматизированной системы и защите ПДн в ИСПДн для старшекурсников по информационной безопасности. **Продолжительность — 120 минут.**

Подготовил: Ижутов Михаил Алексеевич. Дата подготовки: 25 ноября 2026 года.

РПО в материалах означает **разрабатываемое программное обеспечение**. В актуальной сводной версии все шесть тем связаны с одним сетевым маршрутом: users → HTTPS-шлюз → приложение → PostgreSQL; ОС, БД и СЗИ рассматриваются как элементы сетевого контура.

## Подготовка занятия

Все материалы репозитория имеют формат Markdown и открываются непосредственно на GitHub. Для задания по SQL можно скопировать код из Markdown в локальный Python-файл; предусмотрен и вариант разбора без запуска. Остальные задания выполняются по готовым материалам без установки стендов.

Все паспорта, данные, конфигурации и карточки в `practice/data/` **вымышленные учебные**. Нормативные документы представлены ссылками и краткими пояснениями; тексты стандартов не переиздаются в репозитории.
