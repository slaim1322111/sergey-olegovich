# Практика 1. АБАС и программа аудита

**Продолжительность: 10 минут.**

## Задание

По учебному паспорту организации определить применимость трёх режимов и составить две проверки.

## Исходные материалы

- [Материалы практики](data/01-system.md).

Данные в файлах вымышленные и подготовлены для занятия. Работа выполняется локально по выданным материалам; развёртывание инфраструктуры в регламент практики не входит.

## Методика выполнения

1. Прочитать паспорт и выделить данные, владельца системы и границы — 1 мин.
2. Выбрать из реестра нормы для ИСПДн; отдельно оценить основания применения ГИС/КИИ — 2 мин.
3. Назвать сведения, которых не хватает для установления уровня защищённости ПДн — 2 мин.
4. Сформулировать две проверки: критерий, метод, источник доказательства — 2 мин.
5. Заполнить шаблон программы аудита — 2 мин.
6. Проверить, что числовой уровень не назначен без исходных данных — 1 мин.

## Подготовка материалов к сдаче

Таблица применимости трёх режимов, перечень недостающих данных и две строки программы аудита.

Сохранить результат как `П01_Фамилия.md` по [шаблону протокола](../templates/test-protocol.md). Для изображений использовать подписи: действие, цель, наблюдаемый результат. При работе только с готовым файлом указать его имя и проверенные поля.

## Критерии приёмки

- Указаны объект и применимый критерий.
- Доказательство связано с конкретным выводом.
- Подтверждённое замечание отделено от недостающих сведений.
- Предложен повторный тест.
- Вывод отвечает на поставленное задание.
