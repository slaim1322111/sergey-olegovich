# Учебный паспорт объекта

Все сведения вымышленные. ООО «Учебный сервис» обрабатывает обычные персональные данные 1200 клиентов: имя и контакт для заявок. Система — собственное приложение организации; статус ГИС отсутствует. Организация не является государственным учреждением, ГУП или госорганом, не получает информацию ограниченного доступа из ГИС. По условиям кейса организация не является субъектом КИИ, а объект не относится к объектам КИИ.

Компоненты: приложение, Linux-сервер, PostgreSQL, HTTPS-шлюз. Пользователи работают через шлюз; администратор — из выделенной зоны. Тип актуальных угроз для целей определения уровня защищённости ПДн пока не определён. Биометрические и специальные категории ПДн в этом кейсе не обрабатываются.

В границы учебного аудита входят конфигурация доступа, журналы, привилегии БД и настройки шлюза. Исходный код рассматривают только в предоставленном учебном фрагменте. Итог нужен руководителю ИБ как программа дальнейшей проверки.
