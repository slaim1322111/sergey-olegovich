# Учебная база данных

## Назначение ролей

Данные вымышленные. web_app читает catalog и добавляет заявки в requests. analyst читает представление report_view. Администрирование выполняет отдельная роль dba.

Журнал audit_log нужен для расследования изменений. Права на удаление его записей прикладным ролям не требуются. Членство в других ролях в этом упрощённом кейсе отсутствует.

Имеется файл backup.dump и запись «создание копии завершено успешно». Протокола восстановления нет. Задание состоит в предложении целевой матрицы и тестов; подключение к БД не требуется.

Для дополнительной самостоятельной работы можно составить SELECT к pg_roles и information_schema.role_table_grants. Изменения GRANT/REVOKE в рабочей БД в занятие не входят.

## Текущие права

| Роль | Объект | Операция | Разрешение |
|---|---|---|---|
| web_app | роль | SUPERUSER | да |
| web_app | catalog | SELECT | да |
| web_app | requests | INSERT | да |
| web_app | audit_log | DELETE | да |
| analyst | report_view | SELECT | да |
| analyst | requests | UPDATE | да |
