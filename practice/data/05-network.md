# Учебная сеть и TLS

Данные вымышленные. Названия зон обозначают роли компонентов в учебной системе.

## Наблюдаемые потоки

| Источник | Назначение | Порт | Результат | Основание |
|---|---|---|---|---|
| users | gateway | 443 | разрешено | HTTPS-доступ пользователей |
| gateway | app | 8080 | разрешено | передача запросов приложению |
| app | database | 5432 | разрешено | работа приложения с БД |
| admin_zone | gateway_admin | 443 | разрешено | администрирование шлюза |
| users | database | 5432 | разрешено | основание отсутствует |
| users | app | 8080 | разрешено | обход шлюза, основание отсутствует |
