# Анализ защищённости удалённого доступа ведущих к кабинету клуба «В гостях у троллей»

[Общий паспорт клуба и подбор нормативных актов](../1%20%D1%82%D0%B5%D0%BC%D0%B0/club.md)

**Дисциплина** — «Анализ безопасности автоматизированных систем» (АБАС).

Подготовил Ижутов Михаил Алексеевич. Занятие для студентов старших курсов по информационной безопасности.

Ведущие клуба открывают списки записавшихся через кабинет с подключением по VPN. Студент проверяет условия входа, состояние устройства, доступные роли и сетевые маршруты, затем по журналам оценивает отзыв прав.

## Просмотр слайдов

Файлы `.marp.md` можно читать на GitHub. Для показа используйте редактор с поддержкой Marp. Marp CLI также экспортирует презентацию в HTML или PPTX. [Документация Marp CLI](https://github.com/marp-team/marp-cli)

Выполните в папке «2 тема». Для экспорта отдельной лекции подставьте её имя из `lectures/`.

```sh
npx @marp-team/marp-cli presentation.marp.md -o presentation.html
npx @marp-team/marp-cli --pptx presentation.marp.md -o presentation.pptx
```
