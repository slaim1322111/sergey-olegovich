# Материалы преподавателя

Сначала выдайте Д1 без текста Д1‑У. После того как студенты зафиксируют недостающие сведения, выдайте Д1‑У. В экзамене используется другой масштаб ИСПДн, чтобы проверить самостоятельное применение условий УЗ. [Данные практики](case.md) · [Экзамен](exam.md)

## Ожидаемые результаты практик

| Тема | Вывод | Повторная проверка |
|---|---|---|
| Т1 | В область входят обе точки формирования, сегменты связи, приёмник, CRM, БД и журналы. 135 000 клиентов, иные ПДн, тип 3 дают УЗ‑3 по подп. «д» п. 11 № 1119 | При изменении категории, числа субъектов или типа угроз пересмотреть решение |
| Т2 | F5 достигает сетевого порта БД вопреки матрице. Чтение записей не установлено. F6 закрыт | Шлюзы филиалов используют разрешённые F1 и F2, штатный импорт использует F3 и F4. F5 и F6 отклоняются |
| Т3 | M32 подтверждает ошибку привязки прав к идентичности при успешном mTLS. M33 демонстрирует ожидаемый отказ по имени | Для Б допустима очередь Б, очередь А получает отказ. Ожидаемое имя проходит проверку, неверное имя отклоняется |
| Т4 | P42 повторно создал 200 записей. По А/42 всего выросло на 400 записей, ожидается 200. P43 соответствует критерию целостности | Первый приём создаёт 200 записей, идентичный повтор даёт `duplicate` и 0 новых записей. Несовпавший хеш при проверке целостности даёт `invalid`. Повтор ключа с иным, валидным содержимым даёт `conflict` |
| Т5 | R27 сработало первым в F5 по J55. Карточка 7.3 оставляет охват 7.4 неподтверждённым | Зафиксировать отказ F5 и сохранить F1–F4. Запросить формуляр, сведения об исполнении и подтверждение охвата версии |
| Т6 | J61–J64 связывают две попытки с А/42 и подтверждают повторный импорт. J63 показывает лишнее поле «телефон» | В журнале фиксируется `duplicate`, в CRM 0 новых строк по повтору. Для связи используются служебные поля, телефон отсутствует |

Пример заключения. «По выборке подтверждены достижимость порта БД из филиала, допуск отправителя Б к очереди А и повторный импорт А/42. Запись J63 содержит лишнее поле. Версия 7.4 требует документального уточнения. После исправлений нужно проверить сохранение штатных передач и отсутствие второго изменения CRM по А/42».

## Баллы за общий кейс

| Пункт | Критерий |
|---|---|
| Б1 | 1 балл за УЗ‑4 по подп. «б» п. 12 № 1119. 1 балл за иные ПДн менее 100 000 клиентов, которые не являются сотрудниками, и угрозы третьего типа |
| Б2 | 1 балл за вывод о нарушении привязки В к своей очереди и указание критерия отказа чужой очереди |
| Б3 | 1 балл за запрет TCP из филиала к БД и сохранение служебного подключения CRM |
| Б4 | 1 балл за `duplicate` и 0 новых записей при идентичном повторе |
| Б5 | 1 балл за вывод о неподтверждённом охвате 5.1 и запрос документов на исполнение и версию |
| Б6 | 1 балл за журнал CRM с повторным изменением по ключу В/18. 1 балл за исключение почты при сохранении служебных полей для сопоставления |

Эквивалентные по смыслу ответы засчитываются. Баллы практик начисляются отдельно.
