# Анализ защищённости обмена списками участников между площадками клуба «В гостях у троллей»

[Общий паспорт клуба и подбор нормативных актов](../1%20%D1%82%D0%B5%D0%BC%D0%B0/club.md)

**Дисциплина** — «Анализ безопасности автоматизированных систем» (АБАС).

Подготовил Ижутов Михаил Алексеевич. Материалы предназначены для старших курсов направления «Информационная безопасность».

Две площадки передают пакеты с отметками о посещении в центральный реестр клуба. Студенты проверяют маршруты, подлинность сторон, полномочия отправителя, целостность и повторную доставку. Все наблюдения относятся к одной вымышленной системе.

